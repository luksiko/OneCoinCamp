# План реализации Camper Monitor

## Приоритет 1 (Высокий — базовое юзабилити и надёжность)

Самое полезное прямо сейчас для ежедневного использования:

- [x] **1. Контроль свежести мониторинга**
  - Красный статус в UI: «триггер не выполнялся N минут».
  - Кнопка принудительного повторного запуска / сброса триггеров из интерфейса.
  - Уведомление в Telegram о сбое или зависании регулярного опроса.
- [x] **2. Только реальные направления Roadsurfer**
  - После выбора города отправления показывать только фактически доступные Rally-направления.
  - Исключение заведомо невалидных пар городов.
- [x] **3. Экран найденных офферов**
  - Таблица/экран последних результатов в UI.
  - Фильтрация: источник, маршрут, даты, цена, статус («новый» / «уже отправлен»).
  - Кнопка прямого перехода к бронированию оффера.

---

## Приоритет 2 (Средний — автоматизация и гибкость)

- [x] **4. Умные Telegram-уведомления**
  - Фильтры на стороне бота: лимит цены, минимальная и максимальная длительность (дней).
  - Режим «тихих часов» (silent hours) и сводный ежедневный дайджест.
  - Inline-кнопки под сообщениями: «отключить маршрут», «открыть оффер».
- [x] **5. Movacar: страна → город и поиск по всем (wildcard)**
  - Иерархический выбор и фильтрация направлений.
  - Полноценный парсинг конкретных офферов (автомобиль, даты, цена, ссылка).
  - Использование wildcard (`*`) для названий городов.
- [ ] **6. Шаблоны маршрутов и быстрое создание**
  - Региональные пресеты («Германия → Италия», «Бенилюкс → Испания»).
  - Кнопка дублирования существующего маршрута в один клик.
