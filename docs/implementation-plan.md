# План реализации Camper Monitor

## Приоритет 1 (Высокий — базовое юзабилити и надёжность)

- [x] **1. Контроль свежести мониторинга**
  - Красный статус в UI: «триггер не выполнялся N минут».
  - Кнопка принудительного повторного запуска / сброса триггеров из интерфейса и бота (`/check`).
  - Уведомление в Telegram о сбое или зависании регулярного опроса.
  - Автоматическое продление и самовосстановление триггеров (`self-healing`).
- [x] **2. Реальные направления Roadsurfer Rally**
  - Получение станций отправления и фактически доступных назначений через API.
  - Исключение невалидных пар городов.
- [x] **3. Экран найденных офферов в Web App**
  - Таблица/список последних результатов в Telegram Mini App.
  - Фильтрация: источник, маршрут, даты, диапазон цен, статус («новый» / «уже отправлен»).
  - Кнопка прямого перехода к бронированию оффера.
- [x] **3.1. Критические UX/UI фиксы (Срочно)**
  - [x] Индикация "протухания" офферов (🟢 LIVE, 🟡 HURRY, 🔴 GONE) — `OffersTab.vue`.
  - [x] Deep-link из Telegram алертов → карточка оффера в Mini App (`?offer=ID` → scroll + pulse-highlight).
  - [x] Исправление бага с ISO-датами (`formatDate` в `renderDeals()`).
  - [x] Фильтрация дорогих предложений на лендинге (MAX_LANDING_PRICE = 5€).
  - [x] Удаление фейкового `aggregateRating` из JSON-LD и фейковых имён из отзывов.
  - [x] Race condition `updateBotLinks()` — карточки маршрутов исключены из перезаписи.
  - [x] `filterDeals()` — исправлен deprecated `window.event`, передаётся `this`.
  - [x] Админка: кнопки (+30д, -7д) заменены на выпадающее меню действий `⋮`.

## Приоритет 2 (Средний — автоматизация и многопользовательский режим)

- [x] **4. Умные Telegram-уведомления и команды**
  - Интерактивные команды: `/start`, `/help`, `/status`, `/digest`, `/actual`, `/routes`, `/check`.
  - Управление режимом тихих часов через `/silent [on|off|HH:MM-HH:MM]` и в UI.
  - Inline-кнопки под сообщениями: «Забронировать оффер ➔» и «🚫 Отключить этот маршрут».
  - Режим Webhook с валидацией секретного токена (`X-Telegram-Bot-Api-Secret-Token`) и логированием ошибок.
- [x] **5. Movacar: страна → город и поиск по всем (wildcard)**
  - Иерархический выбор и фильтрация направлений.
  - Полноценный парсинг конкретных офферов (автомобиль, даты, цена, ссылка).
  - Поддержка wildcard (`*`) для названий городов и стран.
- [x] **6. Многопользовательское хранение (Cloud Firestore)**
  - Коллекции `users/{telegram_id}/routes`, `settings/filters`, `sent_alerts/{fingerprint}`.
  - Авторизация через JWT RS256 Service Account с кэшированием токенов.
  - Быстрая O(1) проверка повторных алертов.
- [x] **7. Проверка доступности провайдеров (Health Check)**
  - Эндпоинт `checkProvidersHealth` для проверки доступности Roadsurfer, Movacar, Indie Campers, Imoova.
